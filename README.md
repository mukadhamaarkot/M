# מקלדת מקומית — Android

מקלדת מערכת (IME) עם חיזוי מילים מקומי בעברית ובאנגלית. הפרויקט מוגדר ל־Android 6.0 (API 23) ומעלה.

## מה כלול בגרסה הזאת

- שירות הקלדה אמיתי של Android, שאפשר לבחור כמקלדת ברירת מחדל.
- פריסת מקשים עברית ופריסת QWERTY באנגלית.
- שורת שלוש הצעות מעל המקלדת.
- השלמת מילים לפי תחילת המילה והצעת המילה הבאה לפי הקשר בסיסי.
- מילון מקומי ראשוני בעברית ובאנגלית וזוגות מילים נפוצים.
- למידה מקומית של מילים וצירופים שהוקלדו, הנשמרת ב־SharedPreferences במכשיר.
- השבתת חיזוי ולמידה בשדות סיסמה, מספרים, טלפון, כתובות דוא״ל וכתובות אינטרנט.
- אין בפרויקט הרשאת `INTERNET` או קוד תקשורת רשת.

## בניית APK דרך GitHub Actions

1. יוצרים Repository חדש ב־GitHub ומעלים אליו את כל תוכן התיקייה.
2. פותחים בלשונית **Actions** את התהליך **Build Android APK**.
3. לוחצים **Run workflow**.
4. בסיום מורידים את ה־Artifact בשם `OfflineHebrewKeyboard-debug-apk`. בתוכו נמצא `app-debug.apk`.

אפשר לבנות גם מקומית עם Java 17, Android SDK ו־Gradle 8.13 באמצעות `gradle --no-daemon assembleDebug`.

## התקנה והפעלה במכשיר

1. מתקינים את קובץ ה־APK.
2. פותחים את האפליקציה ולוחצים **הפעלת המקלדת**.
3. בהגדרות המקלדות מפעילים את **מקלדת מקומית**.
4. חוזרים לאפליקציה, לוחצים **בחירת המקלדת** ובוחרים בה.
5. פותחים שדה טקסט רגיל ומקלידים.

## חשוב לדעת על איכות החיזוי

זוהי גרסת בסיס עובדת מבחינת מבנה IME וזרימת ההקלדה. החיזוי הנוכחי מבוסס על מילון seed קטן יחסית, דירוג שכיחויות וזוגות מילים. הוא אינו מודל שפה גדול, ולכן הוא עדיין לא מגיע לרמת הדיוק, הכיסוי וההבנה של מקלדות ענן או Gboard. כדי להתקרב לרמה הזאת נצטרך לשלב בהמשך מודל שפה עברי מקומי (למשל מודל קטן ומכווץ שרץ על המכשיר), מילון רחב יותר, ניקוד/נטיות, ותיקון שגיאות הקלדה.

## פרטי build

- Namespace / Application ID: `com.example.offlinekeyboard`
- `minSdk`: 23 (Android 6.0)
- `compileSdk`: 36
- `buildTools`: 35.0.0
- `targetSdk`: 35
- Java 17, Android Gradle Plugin 8.13.2

הפרויקט לא כולל קובץ APK מוכן, כי בסביבת העבודה הנוכחית אין Android SDK מותקן. קובץ ה־APK נבנה ב־GitHub Actions לפי ה־workflow המצורף.
